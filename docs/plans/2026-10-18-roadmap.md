## Collaboration: git-based first **(decided)**

Asynchronous collaboration through git, no server:

* Source control view (status, stage, commit, branches, sync) as the base.
* Readable merges: conflicts shown per file with a side-by-side resolver;
  three-way merge for Typst, LaTeX and Markdown text.
* Comments and suggestions stored in the project as plain files (for example
  `.manang/comments/*.toml`) so they travel with git and survive offline;
  anchored to text positions with a resilient anchor (quote plus context).
* Review mode: suggestions shown inline, accept or reject, author and time.
* Share: "Publish to a git remote" helper and clear status of what is pushed.
* Real-time co-editing comes later on a CRDT. Candidates to evaluate in a spike:
  `yrs` (Rust port of Yjs), Automerge, Loro; transport options: local network
  peer-to-peer or a small relay server. Not decided.

## Sync

* Git sync from the Source control view (`git.sync`), only on user action.
* Folder sync tools (Syncthing, Dropbox, iCloud) already work because projects
  are plain folders; the app must handle external changes gracefully (the
  project watcher exists; conflict prompts for open, unsaved files are needed).
* Settings sync across devices: optional, later.

## AI agent: bring your own key **(decided)**

* Providers are plugins. Claude is the default provider; others (and local
  models, for example through Ollama) can be added. Nothing is sent anywhere
  until the user configures a provider and accepts what is shared.
* API keys stored in the operating system keychain, never in project files or
  settings TOML.
* Features, in order: writing assistant on a selection (rewrite, shorten,
  translate, explain an error); compiler self-healing as a reviewable diff;
  citation and claim checking (built on `citations.verify`); prompt to
  document in a template; prompt to slides.
* Every AI change is a diff the user accepts; no silent edits.
* Plugins expose tools to the agent through the kernel's `register_agent_tool`
  hook, so third-party document types (docx, figures) become agent-drivable.
* Cost and privacy controls: per-request preview of what is sent, token and
  cost display, per-project opt-out.
* Engineering: agent orchestration in Rust (Tokio for streaming I/O), streamed
  tokens to the UI over a Tauri channel, cancellable requests.
