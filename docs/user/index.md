# Manang User Guide

Manang is a local-first desktop app for writing papers, theses and slides in Typst, LaTeX or Markdown, with live preview, figures, references and an AI helper.

You can draw vector figures, render diagrams from plain text, keep versions of your work, and write together with co-authors. Your files stay ordinary files on your own disk.

## Where to start

1. If you have not installed Manang yet, read [Install Manang](install.md).
2. If you are opening Manang for the first time, start with [Getting Started](getting-started.md) to set up a project and learn the workspace layout.
3. If you want to write and format prose or equations, read [Writing](writing.md).
4. If you want to compile documents, inspect pages, and export publication files, read [Preview and PDF](preview-and-pdf.md).
