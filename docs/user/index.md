# Manang User Guide

Manang is a fast, local-first scientific authoring and illustration desktop application. You can write papers, reports, and lecture slides in Typst, LaTeX, and Markdown, draw vector figures, and render diagrams from plain text.

## Where to start

1. If you are opening Manang for the first time, start with [Getting started](getting-started.md) to set up a project and learn the workspace layout.
2. If you want to write and format prose or equations, read [Writing](writing.md).
3. If you want to compile documents, inspect pages, and export publication files, read [Preview and PDF](preview-and-pdf.md).

## Guide pages

- **[Getting started](getting-started.md)**  
  Run Manang from source, use the Home screen and templates, manage Home trash, create or open projects, and navigate the main window layout.

- **[Writing](writing.md)**  
  Write in Typst, LaTeX, or Markdown, convert Markdown to Typst, format source files, check spelling, manage your personal dictionary, insert symbols and snippets, and view document word counts.

- **[The Visual editor](visual-editor.md)**
  See Markdown and Typst formatted as you write (headings, bold, lists, formulas, images), switch between Source and Visual with `Ctrl+Alt+V`, and use the formatting toolbar. The file stays plain text.

- **[Preview and PDF](preview-and-pdf.md)**  
  Control preview layouts, compile documents automatically, use the built-in PDF viewer, jump between source text and the preview with SyncTeX, export PDFs, and configure TeX Live for LaTeX.

- **[Fixing errors](fixing-errors.md)**  
  Use the Fix button, the editor quick fix and Fix all for small compile errors such as a missing package, undo a fix, and turn automatic fixes on or off.

- **[Figures and diagrams](figures-and-diagrams.md)**  
  Draw vector sketches in the figure studio, use bound arrows and frames, render text diagrams in Mermaid, Pikchr, and ASCII format, and include figures in your documents.

- **[References and bibliographies](references.md)**  
  Load bibliography files, choose citation styles, search entries, insert citations into your text, and verify references against online registries.

- **[Projects and files](projects-and-files.md)**  
  Manage files in the sidebar tree, view images and PDFs, launch external system applications, delete files safely, use Home trash, and commit changes with the source control panel.

- **[Edit together live](edit-together-live.md)**  
  Share one text file for real-time co-editing with an encrypted invite, see collaborators' carets, keep working through a dropped connection, and understand what the relay can and cannot see.

- **[Crash recovery and safety copies](crash-recovery.md)**  
  Understand automatic hot exit recovery snapshots, recover unsaved work after unexpected quits, and inspect automatic safety copies.

- **[Version history and restore](version-history.md)**  
  Capture named project milestone snapshots, browse the history timeline, inspect visual diffs, and restore previous drafts safely.

- **[Share and get updates](share-and-get-updates.md)**  
  Connect a shared address once, share your saved versions with co-authors, and bring their work into yours without losing anything.

- **[The Trash](trash.md)**  
  Manage deleted projects on the Home screen, restore trashed projects, perform permanent purges, and recover deleted workspace files.

- **[Templates](templates.md)**  
  Scaffold ready-to-compile projects from built-in Typst, LaTeX, and Markdown templates completely offline.

- **[Settings and shortcuts](settings-and-shortcuts.md)**  
  Adjust contextual, user, and project settings, switch themes, search keyboard shortcuts, and customize keybindings.

- **[Menus and shortcuts](menus-and-shortcuts.md)**  
  Complete reference for every menu bar item (File, Edit, View, Go, Build, Help), mnemonics, keyboard navigation, and surface-specific shortcuts.

- **[Plugins](plugins.md)**  
  Learn how built-in and sandboxed WebAssembly plugins work, understand permissions, and interpret plugin status indicators.

- **[Troubleshooting](troubleshooting.md)**  
  Find application logs on Linux, macOS, and Windows, open developer inspection tools, fix TeX installation errors, resolve Linux Wayland graphics issues, and report bugs.
