# Manang documentation

One line per area. Plans and research are dated records of what was intended or found at the time; the ADRs, the CHANGELOG and the user guide say what is true now.

| Area | Where | What is in it |
| :--- | :--- | :--- |
| User guide | [`user/`](user/index.md) | How to use Manang, written for non-developers: install, writing, preview, figures, references, live editing, plugins, troubleshooting |
| AI assistant | [`ai/using-the-agent.md`](ai/using-the-agent.md) | Working with the assistant that proposes edits |
| Beta testing | [`beta/`](beta/tester-guide.md) | Tester guide, known issues, release notes template |
| Release notes | [`release-notes/`](release-notes/v0.1.0-beta.1.md) | Notes for each published release |
| Decisions (ADRs) | [`adr/`](adr/) | Architecture decisions and their status (WASM plugins, live editing, project-wide live sessions, plugin registry, plugin SDK extraction) |
| Plans | [`plans/`](plans/2026-10-20-master-plan.md) | The master plan (start here), the roadmap and design plans; each older plan carries a status line at the top |
| Research | [`research/`](research/) | Spikes and studies, including the draft cryptographic design for live collaboration (not implemented) |
| Plugin authors | [`plugins.md`](plugins.md), [`plugins-publishing.md`](plugins-publishing.md) | Writing, building and publishing a plugin |
| Formats | [`formats.md`](formats.md) | Every file Manang reads or writes, its version, and what happens across versions |
| Building | [`building.md`](building.md) | Build and run from source |
| Design | [`design-system-additions.md`](design-system-additions.md) | Additions to the Fundaments design system |
| Operations | [`ops/`](ops/engine-release.md) | Releasing the LaTeX engine; running the plugin registry (ops/registry.md) |
| Marketing | [`marketing/positioning.md`](marketing/positioning.md) | Positioning notes |
| Working notes | [`notes/`](notes/) | Internal working notes from agent sessions; may be out of date |
