**The first public beta of Manang**, the local-first suite for writing papers, theses and slides in Typst, LaTeX or Markdown, with the figures drawn in the same app.

It is a beta: expect rough edges, and please report them. Your files are plain text on your own disk, so trying it costs nothing.

## Download

| System | File |
| :--- | :--- |
| Windows (64-bit) | `.exe` installer or `.msi` |
| macOS, Apple silicon | `aarch64.dmg` |
| macOS, Intel | `x64.dmg` |
| Linux | `.deb`, `.rpm` or `.AppImage` |

Installers are **not signed yet**: Windows SmartScreen and macOS Gatekeeper will warn you the first time. [Install guide](https://github.com/Fundaments-Work/Manang/blob/main/docs/user/install.md) has the two-step workaround, and `SHA256SUMS.txt` lets you verify the files.

## What is in it

- **Typst, LaTeX and Markdown** with live preview, a real PDF viewer, and click-to-jump between source and page.
- **Figure studio:** vector shapes, connectors that stay attached, typeset formulas, Mermaid, Pikchr and ASCII diagrams, saved as a source file plus clean SVG.
- **Visual editor** for Markdown and Typst, switchable with the source (`Ctrl+Alt+V`).
- **Writing help that asks first:** a small AI agent (your own API key, nothing sent by Manang itself) that proposes diffs and never edits without you; one-click fixes for common compile errors.
- **Edit together live** on a text file through an end-to-end encrypted relay; invitation links carry the key, the relay only sees ciphertext. Invite-only by design.
- **Plugins:** a signed plugin registry at `registry.fundaments.work`, with a plugin page, permissions you read before installing, and uninstall. Plugins run in a WebAssembly sandbox.
- **Safe by default:** autosave, crash recovery, a recoverable trash, version history with diffs.
- **References:** BibTeX and CSL citations with an online verifier.

## Known limits

- Installers are unsigned (see above). There is no in-app updater yet.
- LaTeX needs a TeX installation. The optional built-in engine is not published yet.
- Live editing covers one text file per session. Comments and project-wide sessions come later.
- The plugin registry is new and empty; first-party plugins arrive in the next releases.
