**Manang 0.1.0-beta.1** is the first public beta of Manang, the local-first suite for writing
papers, theses and slides in Typst, LaTeX or Markdown, with the figures drawn in the same app.

This build replaces the first beta.1 upload. That one shipped a 120 MB AppImage with WebKitGTK
inside, could not fetch the built-in LaTeX engine, and carried a Markdown bug that could turn
links into plain text. If you installed it, reinstall from the files below.

It is a beta: expect rough edges, and please report them. Your files are plain text on your own
disk, so trying it costs nothing.

## Download

| System | File |
| :--- | :--- |
| Windows (64-bit) | `.exe` installer or `.msi` |
| macOS, Apple silicon | `aarch64.dmg` |
| macOS, Intel | `x64.dmg` |
| Linux | `.deb`, `.rpm` or `tar.xz` |

On Linux, one command picks the right one for your distribution and checks it against
`SHA256SUMS.txt` before installing anything:

```bash
curl -fsSL https://raw.githubusercontent.com/Fundaments-Work/Manang/main/scripts/install-linux.sh | bash
```

Installers are **not signed yet**: Windows SmartScreen and macOS Gatekeeper warn on the first
launch, and the [install guide](https://github.com/Fundaments-Work/Manang/blob/main/docs/user/install.md)
has the two-step workaround.

### Reinstalling over the first upload

On Windows and macOS, run the new installer over the old version.

On Linux, remove the earlier install first if you used the script: it lives in `~/.local` and
would otherwise shadow the new package.

```bash
curl -fsSL https://raw.githubusercontent.com/Fundaments-Work/Manang/main/scripts/uninstall-linux.sh | bash
```

Your settings and your files are untouched; only the app is removed.

## LaTeX without installing TeX

The optional built-in engine is now published. With no TeX installation on your machine, open a
`.tex` file and choose **Preview > Download the built-in engine** (also in **Settings > LaTeX**).
The consent window names the server, the size and the SHA-256 before anything is fetched; the
binary is about 48 MB, is verified against a manifest compiled into the app, is started once to
prove it runs, and is installed atomically. Manang never links it: it stays a separate process
you can remove from the same menu.

Available now on **Linux x86-64 and arm64**. It fetches LaTeX packages on demand the first time
you compile, so the first compile needs a network connection and takes a minute or two; after
that it is about a second. Windows and macOS builds follow.

If you already have TeX Live, MiKTeX or MacTeX, Manang uses it first and says so in the compile
report. Nothing changes for you.

## Smaller Linux downloads

The AppImage is gone, and the `.deb` is smaller.

Tauri builds AppImages with linuxdeploy, which follows the binary's shared libraries and copies
the entire GTK and WebKitGTK runtime into the file. Ours was 120 MB: 91 MB of `libwebkit2gtk` and
32 MB of `libjavascriptcoregtk`, around a 46 MB application. That copy is a browser engine frozen
at build time, so it never gets the security updates your system's does, and it is three times
the size of everything else we ship.

What replaces it:

- **`.deb`**, recompressed with xz: **45.8 MB → 31.6 MB**. `sudo apt install ./Manang_*.deb`.
- **`.rpm`** for Fedora and openSUSE, unchanged.
- **`Manang_<version>_amd64.tar.xz`**, about the same 31 MB, for everything else (Arch,
  Slackware, Gentoo, NixOS). Unpack it and run `usr/bin/manang`, or let the script do it with
  `--bundle tar --user`. It installs into `~/.local`, needs no root, and uses your system's
  WebKitGTK 4.1 exactly like the packages do. On Arch that is `sudo pacman -S webkit2gtk-4.1`.

The install script picks the right one for your distribution, as before.

## An installer that knows what a beta is

```bash
... | bash -s -- --list            # every published release, newest first
... | bash -s -- --beta            # the newest pre-release
... | bash -s -- --stable          # the newest release that is not a pre-release
... | bash -s -- --version beta    # same as --beta
... | bash -s -- --dry-run         # show what would happen, change nothing
```

With only pre-releases published so far, `--stable` tells you that no stable release exists and
installs nothing. Setting `GITHUB_TOKEN` (any token, no scopes) lifts GitHub's anonymous rate
limit of 60 requests an hour.

## Fixed

- **Markdown in the visual editor could lose links.** The parser decides whether an inline link is
  a link by looking for reference definitions anywhere in the document, so writing `[r]: http://x`
  at the end of a file could turn a link in the middle of it into plain text (or the other way
  round) until the file was reopened. An edit that can change a definition now re-reads the
  document. Found by a property test that compares the incremental parse with a fresh one on
  every edit.

## Known limits

- Installers are unsigned and there is still no in-app updater.
- The built-in LaTeX engine is Linux-only for now; Windows and macOS use a TeX installation.
- Live editing covers one text file per session. Comments and project-wide sessions come later.
- The plugin registry is still young; first-party plugins arrive in a later release.
