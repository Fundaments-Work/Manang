# Manang

> *The High-Performance Scientific Authoring & Illustration Suite*  
> **Made by Fundaments.work**

Manang combines **Typst**, **LaTeX (Tectonic)**, **Markdown**, **Excalidraw (MIT)**, and a dedicated **CeTZ / TikZ Visual Studio** into a local-first, ultra-fast authoring suite.
